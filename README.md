# 儒释道学习

## 介绍

儒、释、道三家典籍学习记录摘要。  
同时发心整理三家经典文集，使其存在于网络之中，并能自由下载和修改完善，**欢迎大家参与**。  
文件使用 markdown 格式，在方便阅读的同时也能及时修改其中抄录错误。并可以以代码形式加以追踪回溯。

## 初步约定

1. 文件统一采用 **UTF-8** 编码格式；
2. 文件扩展名为 `.md`；
3. 内部书名为一级标题（`#` 加空格），其余标题递减；
4. **公版原则**：仅整理公版古籍原文，不收录任何当代译者独占版权的现代注释/翻译。  
   引用古代注疏（已公版）时须注明版本。
5. 每部经典头部应包含 YAML front-matter（书名/朝代/作者/类别/底本），模板见 `.github/metadata/books.yml`。
6. **简体优先**：正文一律使用简体中文；底本若为繁体应转为简体。  
   **无简体中文对应**的文字（通假字、异体字、避讳字、佛道音译专名、梵文巴利文译音等）保留原字。详见 [CONTRIBUTING.md](CONTRIBUTING.md)。

## 版权与来源

本项目仅整理已**进入公版领域**的中文古籍原文（佛经、道经、儒家经典等），底本主要参考：
- 佛经：CBETA / 大正藏（公版）
- 道经：道藏、道藏辑要（公版）
- 儒经：十三经注疏、四书章句集注（公版）

**不收录**任何现代编者独占版权的整理本（如当代注译本等）。如有侵权，请[提交 issue](https://github.com/sxmwhl/confucianism-buddhism-taoism/issues)。
